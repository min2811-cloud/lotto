# Workflow: 주간 로또 번호 생성

## 목표

매주 새 회차 추첨(토요일 밤)이 끝난 뒤, 최신 당첨번호를 반영해서
추천 번호 20게임을 만들고 PNG 이미지로 사장님께 전달한다.

## 언제

- 토요일 21:00 이후 ~ 다음 회차 구매 마감(토요일 20:00) 전 아무 때나
- 보통 **일요일 아침**에 한 번 실행

## 실행 방법 (수동)

1. 프로젝트 폴더의 `로또번호.bat` 더블클릭
   - 또는 터미널에서 `.venv\Scripts\python.exe run.py`
2. 자동으로 진행되는 일:
   - 최신 당첨번호 내려받기 (`data/lotto_draws.json` 갱신)
   - 규칙대로 20게임 생성
   - `data/output/` 에 PNG 저장 + 화면에 이미지 열림
   - 카카오톡 연결이 돼 있으면 "나에게 보내기"로 전송

## 필요한 입력값

없음. 번호 데이터는 자동으로 가져온다.

## 번호 생성 규칙 (코드: `tools/lotto_rules.py`)

직전 회차 = 가장 최근 당첨번호 6개 (보너스 제외)

| 그룹 | 내용 | 게임 수 |
|---|---|---|
| overlap0 | 직전 회차와 겹치는 숫자 0개 | 4 |
| overlap1 | 직전 회차와 겹치는 숫자 1개 | 4 |
| overlap2 | 직전 회차와 겹치는 숫자 2개 | 2 |
| stat_recent | 최근 100회차 기준: 다출 15개 중 2개 + 소출 15개 중 2개 + 나머지 15개 중 2개 | 5 |
| stat_all | 전체 회차 기준: 다출 15개 중 2개 + 소출 15개 중 2개 + 나머지 15개 중 2개 | 5 |

- 다출/소출 15개: 출현 횟수로 1~45를 정렬 (동점이면 작은 숫자가 앞순위).
  상위 15 = 다출, 하위 15 = 소출, 가운데 15 = 나머지.
- `stat_recent` 는 최근 100회차, `stat_all` 은 1회차부터 전체를 따로 집계해 순위를 매긴다.
- 20게임은 서로 중복되지 않게 뽑는다.

## 결과물 형태

- PNG 한 장 (`data/output/lotto_<회차>회_<날짜시간>.png`), 세로형, 휴대폰에서 보기 좋게.
- `data/output/latest.png` 는 항상 가장 최근 결과.
- 카카오톡: feed 메시지 + 이미지.

## 문제 발생 시 대응

| 증상 | 대응 |
|---|---|
| "온라인 데이터를 못 받았습니다" | 인터넷 확인. 저장된 데이터로 계속 진행됨. 데이터 미러가 죽었으면 `tools/lotto_data.py` 의 URL 교체 필요 |
| 카카오톡이 안 옴 | `kakao_setup.md` 대로 연결했는지 확인. `python -m tools.kakao_auth` 재실행 |
| 카카오 이미지 업로드 실패 | 이미지는 `data/output/` 에 있으니 직접 공유. 원인 파악 후 이 문서에 기록 |
| 최신 회차가 반영 안 됨 | 미러 갱신이 몇 시간 늦을 수 있음. 일요일 늦게 다시 실행 |

## 나중에 자동화하려면

- 윈도우 "작업 스케줄러"에 매주 일요일 08:00, `로또번호.bat` 실행 등록
- 또는 클라우드 예약 실행으로 전환 (사장님께 먼저 확인)
