# workflows/

각 반복 업무의 **단계별 지시서**를 모아두는 곳입니다.

하나의 Workflow 파일에는 이런 내용이 들어갑니다:

- **목표** — 이 업무가 끝나면 무엇이 나오는가
- **필요한 입력값** — 시작하려면 사장이 무엇을 알려줘야 하는가
- **실행할 Tool** — `tools/` 안의 어떤 파일을 쓰는가
- **결과물 형태** — 구글 시트 / Gmail / 드라이브 중 어디로, 어떤 모양으로 나가는가
- **문제 발생 시 대응** — 자주 터지는 오류와 해결 방법

새 Workflow 는 사장의 허락을 받고 만듭니다. 삭제도 마찬가지입니다.
